# 27 Things

An interactive birthday keepsake built as a collection of 27 memories\.

Each memory is presented as a photograph with a note tucked behind it, with a few small interactive details throughout\.

Built with plain HTML, CSS, and JavaScript and hosted with GitHub Pages\.
